# Conventional Commit messages

Format:

```text
type: imperative summary
```

Use lowercase, present tense, no trailing period, and at most 100 characters.

Types:

- `feat`: new behavior
- `fix`: bug fix
- `test`: test-only change
- `docs`: documentation-only change
- `refactor`: behavior-preserving code change
- `build`: dependencies or build system
- `ci`: CI configuration
- `chore`: maintenance outside source and tests

Use the body only when it explains why the change exists.
